# Αναβάθμιση υλικολογισμικού WB200

**[English — πλήρης οδηγός](../README.md)** · **[Όλες οι γλώσσες](../README.md#-languages)**

Αναβαθμίστε το υλικολογισμικό ενός HyFix WB200 (σταθμός ADS-B Wingbits) από τη γραμμή εντολών. Επαληθευμένο σε πραγματικό υλικό: `2.0.33 → 2.0.51`.

> Σύντομος οδηγός. Η πλήρης τεκμηρίωση — ολόκληρος ο πίνακας τελικών σημείων, αναβάθμιση εκτός σύνδεσης σε συγκεκριμένη έκδοση και όλες οι παγίδες — βρίσκεται στο [αγγλικό README](../README.md).

## Γρήγορη εκκίνηση

Αντικαταστήστε το `<IP>` (προεπιλογή `192.168.10.1`), το `<SN>` (σειριακός αριθμός) και το `<TOKEN>`.

```bash
# 1. Διαβάστε την κατάσταση και πάρτε τον σειριακό αριθμό — χωρίς σύνδεση
curl -s http://<IP>/action/devStatus

# 2. Συνδεθείτε — ο κωδικός ΕΙΝΑΙ ο σειριακός αριθμός. Η απάντηση είναι το token
curl -s -X POST http://<IP>/action/login \
  -H "Content-Type: application/x-www-form-urlencoded" -d "mkey=<SN>"

# 3. Ξεκινήστε την αναβάθμιση
curl -s -X POST http://<IP>/action/ota_online -b "USER=<TOKEN>" \
  -H "Content-Type: application/x-www-form-urlencoded" -d "protocol=ftp"
```

Ή αφήστε το σενάριο να τα κάνει όλα:

```powershell
.\scripts\upgrade-wb200.ps1        # Windows
```
```bash
./scripts/upgrade-wb200.sh         # Linux / macOS
```

## Προϋποθέσεις

Διαβάστε το `http://<IP>/action/devStatus` — δημόσιο, χωρίς σύνδεση — και ελέγξτε:

- `inupgrade` = `0`, αλλιώς εκτελείται ήδη αναβάθμιση
- `wiredIP` = `ONLINE`, ή συνδεδεμένο WiFi
- η συσκευή έχει πρόσβαση στο διαδίκτυο

Το `minerStatus = MINING` είναι η ισχυρότερη απόδειξη πρόσβασης στο διαδίκτυο, αλλά **δεν αποτελεί προϋπόθεση**. Σε εσωτερικό χώρο, χωρίς ελεύθερη θέα στον ουρανό για την κεραία, ο miner δεν φεύγει ποτέ από την κατάσταση `WAITING` — αυτό είναι φυσιολογικό και δεν εμποδίζει την αναβάθμιση.

## Τι συμβαίνει

| Χρόνος | Συμβάν |
|---|---|
| ~10 δευτ. | Το υλικολογισμικό εντοπίζεται στον διακομιστή του κατασκευαστή |
| ~3–4 λεπτά | Λαμβάνεται και εγγράφεται — χωρίς καμία ένδειξη |
| έπειτα | Η συσκευή επανεκκινείται μόνη της, οι συνδέσεις πέφτουν |
| ~1 λεπτό | Ξανά online, το `inupgrade` παραμένει `1` |
| λίγα λεπτά | Το `inupgrade` γίνεται `0` — ολοκληρώθηκε |

> ⚠️ **Μη διακόψετε την τροφοδοσία και μην αποσυνδέσετε το καλώδιο δικτύου** κατά την αναβάθμιση. Κινδυνεύετε να αχρηστεύσετε τη συσκευή.

## Επιβεβαίωση

```bash
curl -s http://<IP>/action/devStatus
```

Ολοκληρώθηκε όταν το `fwVer` δείχνει τη νέα έκδοση **και** το `inupgrade` = `0`.

Η πρόοδος μεταδίδεται ζωντανά μέσω WebSocket στο `ws://<IP>:8080/mcm` — δείτε το [`scripts/ws-monitor.py`](../scripts/ws-monitor.py). Η πτώση της σύνδεσης σημαίνει ότι το υλικολογισμικό γράφτηκε και η συσκευή επανεκκινείται· δεν είναι σφάλμα.

## Παγίδες

- **Το `/action/debug_ping` δέχεται αριθμητικό κωδικό (`ping=2`), όχι διεύθυνση IP.** Με IP απαντά `no ip / Get addr error`, που μοιάζει με «χωρίς διαδίκτυο» ενώ δεν είναι.
- **Ο διαχωριστικός χαρακτήρας της έκδοσης αλλάζει μεταξύ εκδόσεων:** `WB200_v2.0.33` → `WB200-v2.0.51`. Μη συγκρίνετε ποτέ την έκδοση με σταθερή συμβολοσειρά.
- **Το `inupgrade` παραμένει `1`** για 2–3 λεπτά αφότου η συσκευή επανέλθει online. Η συσκευή μπορεί να επανεκκινηθεί περισσότερες από μία φορές.
- **Το `health: WiFi is not connected!` είναι ακίνδυνο** όταν χρησιμοποιείτε Ethernet — η συσκευή είναι ταυτόχρονα σημείο πρόσβασης και ενσύρματος πελάτης.
- **Δεν μπορείτε να επιλέξετε έκδοση online.** Ο διακομιστής του κατασκευαστή παρέχει πάντα το νεότερο υλικολογισμικό. Για συγκεκριμένη έκδοση χρησιμοποιήστε την αναβάθμιση εκτός σύνδεσης από τον αγγλικό οδηγό.

## ⚠️ Ασφάλεια

Το `/action/devStatus` είναι δημόσιο και αποκαλύπτει τον σειριακό αριθμό — που είναι επίσης ο κωδικός πρόσβασης. Το token συνεδρίας δεν είναι παρά `base64("user:" + SN)`. Πρακτικά: όποιος φτάνει στη συσκευή μέσω δικτύου μπορεί να την επαναρυθμίσει ή να την επαναπρογραμματίσει. **Ποτέ** μην εκθέτετε τη θύρα 80 του miner στο διαδίκτυο· κρατήστε τον σε αξιόπιστο τοπικό δίκτυο.
